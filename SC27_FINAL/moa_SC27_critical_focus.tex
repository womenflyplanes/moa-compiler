Then when the machine has shape (levels of memory, size of buffers, whatever can be deterministically calculated always, based on epsilons that we know exist, the noise, but it's small) then DNF is transformed to an offset in a uniform memory changing every index into an offset, e.g. for every $ivec$ in final result it is related to address + offset assuming contiguity. e.g. $ivec \psi A$ for any dimension is equivalent to $(rav A)[\gamma(ivec,\rho A)]$. Then we know all indices, through definitions $(iota \rho A)\psi A \equiv A[(iota \rho A; \rho A)]$. Then we begin to dimension lift, thus $(\prod \rho A)_{data}$ must be $(\prod \rho A)_{machines}$.
