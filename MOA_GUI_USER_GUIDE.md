# Historical GUI status

The old GUI illustrates fixed cost formulas. It is not a source compiler or an
independent certificate of measured device performance, energy, cost or heat.
Previous five-device/proof claims in this guide are superseded by the
[correctness audit](docs/COMPILER_AUDIT_20261124.md).

Use [the current compiler architecture and commands](docs/MOA-UNIVERSAL-IR.md)
for structured DNF, ONF and lifted ONF output and reproducible checks.
Historical GUI code remains available for traceability; its model values must
not be presented as measurements or validated predictions.
