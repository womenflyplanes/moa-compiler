\section{Frontend: Your Hand-Derived $\psi$}

From Mullin (1988) dissertation. Five primitives:
\begin{itemize}
\item $\rho A$: shape $\langle d_0,...,d_{r-1}\rangle$, $\tau(A)=\prod d_i$
\item $\iota n = \langle 0,...,n-1\rangle$
\item $\vec{i}\psi A$: selection, $\rho(\vec{i}\psi A)=\tau(\vec{i})\downarrow \rho A$
\item $\gamma(\vec{v},\vec{s})=\sum_{k} v_k \prod_{j=k+1}^{r-1} s_j$ row-major offset
\item $\text{rav } A$: flatten
\end{itemize}

Core rewrite: $\psi$-reduction. Push $\vec{i}\psi$ inward through $\Omega$ until no intermediate remains.

DNF Definition: $\forall \vec{i}, \vec{i}\psi \text{Output} = f(\text{inputs at indices})$ — closed form.

Example you derived: $R = \langle5,6,7\rangle +_{\Omega\langle0,1\rangle} (3\;4\;\rho)\iota12$, $\rho R=\langle3,4\rangle$, DNF: $\langle i,j\rangle\psi R = \langle i\rangle\psi\xi_l + \langle i,j\rangle\psi\xi_r$. 15 reads, 0 intermediate writes.

\section{Omega Subset We Need}

Full $\Omega$ lifts binary $f$ over dimensions: $\xi_l f_{\Omega(\sigma_l,\sigma_r)}\xi_r$, $\rho = \sigma_l\downarrow\rho\xi_l \# \sigma_r\downarrow\rho\xi_r$, $m=(\delta\xi_l-\sigma_l)\lfloor(\delta\xi_r-\sigma_r)$.

We need subset:
\begin{enumerate}
\item $+_{\Omega\langle0,1\rangle}, \times_{\Omega\langle0,1\rangle}$ for broadcast add/mul (softmax, attention scores)
\item $+_{\Omega\langle1,1\rangle}$ reduction for dot products $QK^T$, sum over $d_k$
\item $\max_{\Omega\langle1\rangle}$ for stable softmax: $m=\max_i S_i$
\item Transpose-free: $K^T$ eliminated by $\psi$-reduction, not materialized
\end{enumerate}

No need full arbitrary $\Omega$ nesting — only these 4 patterns cover Papers I-IV forward, backward, decode, block (RMSNorm, gated MLP).

\section{Middle: DNF as Verified IR}

IR = DNF expression tree with $\psi$ leaves. Properties:
\begin{itemize}
\item Eliminates $G_A,G_S,G_{sc}$ in backward (Paper II) as scalars via substitution
\item Decode: $(d_k+nd_k+nd_v+d_v)\times4$B DRAM, $\|\text{err}\|_\infty\le2e-7$, ONF kernel $=0$ exact IEEE-754 (Paper III)
\item KV-cache: $K_{new}=K_{old}\# k_t$, $O(d_k+d_v)$ append via concatenation $\#$ (Paper III)
\item GQA/MQA: $\psi$-selection, proven $h_q/h_{kv}$ reduction (Paper III)
\end{itemize}

Lower bound theorem: $O(nd_k+nd_v)$ matches information-theoretic minimum.

\section{Portability Constraint: Only OpenMP, OpenACC, OpenMPI}

Per requirement: NO CUDA, NO HIP, NO vendor intrinsics. Only portable, standards-based parallel paradigms:

\begin{itemize}
\item \textbf{OpenMP} for multicore CPU: \texttt{\#pragma omp parallel for} over ONF starts/stops/strides. Maps $\gamma$ offset to CPU thread blocks. Handles NUMA via \texttt{OMP\_PROC\_BIND}, \texttt{OMP\_PLACES}. Explains 535x vs $<$3x result: same DNF, different OpenMP place binding.
\item \textbf{OpenACC} for GPU: \texttt{\#pragma acc parallel loop gang worker vector} over ONF. Proven in Paper III: $\|err\|_\infty=0$ exact IEEE-754. Coalesced via $\gamma$ contiguous last index. Atomic fix 2.00x $\rightarrow$ 2.5x done via \texttt{\#pragma acc atomic} restructuring only in ONF.
\item \textbf{OpenMPI} for distributed: Domain decomposition via MoA shape split $\rho A = \langle n \rangle = \langle n_0 \# n_1 ... \rangle$. $\#$ is MoA concat, maps directly to \texttt{MPI\_Scatterv/Gatherv}. KV-cache append $K_{new}=K_{old}\#k_t$ is MPI halo via $\psi$-selection.
\end{itemize}

All three are \textbf{directive-based}, preserve DNF semantics. No code rewrite for new machine, only ONF $\gamma$ variant: $\gamma^{row}$ for C/OpenMP, $\gamma^{col}$ for Fortran/OpenACC, $\gamma^{tiled}$ for MPI block.

C vs Fortran anomaly resolved: Same DNF, C+OpenMP faster on CPU, Fortran+OpenACC faster on GPU due to compiler's $\gamma$ lowering, not algorithm. 3.17x time gap matches 3.35x stall gap — portable paradigms expose stall, vendor kernels hide it.

\section{Backend: ONF via $\gamma$ and Dimension Lifting}

ONF: starts, stops, strides. $\gamma$ maps $\langle i,j\rangle$ to offset $i*s_1+j$.

Dimension lifting: treat hardware as arrays of known shape: CPU cores $\langle c\rangle$, GPU SMs $\langle sm, warp, lane\rangle$, NUMA nodes.

Hardware optimization = ONF rewrite only:
\begin{itemize}
\item GPU regression: 2.00x atomics → restructure ONF strides, 2.5x speedup (Paper V, arXiv:2609.33916)
\item Topology: 535x NUMA penalty vs $<$3x oversubscription — same DNF, different $\gamma$ costs
\item C vs Fortran: faster in C on CPU, Fortran on GPU, 3.17x time gap matches 3.35x stall gap — compiler chooses $\gamma^{row}$ vs $\gamma^{col}$ variant $\sum v_k\prod_{j=0}^{k-1}s_j$
\end{itemize}

DNF fixed, ONF tunable — correctness by construction.
