\section{Interpretation}
\begin{itemize}
\item \textbf{2.00x $\rightarrow$ 2.5x:} Same DNF, different ONF. Atomic contention measured via Nsight, fixed by private accumulation + reduce. Proof that $\gamma$ restructuring changes cost not meaning.
\item \textbf{535x NUMA vs $<$3x oversubscription:} Same DNF, $\gamma_{Numa}$ placement. T\_local vs T\_remote 535x. Fix: proc\_bind(close).
\item \textbf{3.17x/3.35x C vs Fortran:} $\gamma^{row}$ vs $\gamma^{col}$. Time gap matches stall gap, compiler chooses layout.
\item \textbf{reached(d):} 5 devices: Delta A100, MI100, Bridges-2 H100, Expanse V100, Stampede3 Max 1550. All M1exp=36, Pd=9, Xd=0, Cd=36 pinned, Rd 0.004-0.028. Predictive closure.
\end{itemize}
