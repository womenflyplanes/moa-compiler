# Synchronized CC27 manuscript

Build `main.tex` with `bash build.sh` using TeX Live and the ACM class dependencies.
The main PDF includes the completed Papers I–IV correspondence result, original
Paper I hardware evidence, future-work boundary and all references. References
remain in the main PDF and are excluded from the ten-page text/figure limit.
No appendix or separate reviewer supplement is needed to read the main argument.

The source includes all figure PDFs and PNGs. This variant is anonymous.
The full research evidence package is separate; it is not automatically an
anonymous reviewer artifact. Any uploaded supplement must undergo its own
anonymity check.
