## Major submission blockers

1. **Compiler versus specialized emitter.** The trace emitter consumes a fixed-schema saved DNF/ONF, not a general MoA expression. Implement independently testable source AST to psi-reduced DNF.
2. **Omega not yet connected to code generation.** The finite query-ownership module proves coverage for shaped partitions but does not control emitted C or consume the ten-field machine property array. Connect its verified certificate to the emitter and test distinct shapes.
3. **Proof scope.** The online summary induction, row-major gamma bijection and finite query partition arguments are exact-real or discrete proofs under stated assumptions. They do not prove arbitrary compiler correctness, floating-point bitwise equivalence, or all instruction realizations.
4. **Independent hand-derived DNF comparison missing.** Reconcile different archived observable and shape contracts, then independently reduce the hand and compiler expressions.
5. **Performance claims require actual data.** Contiguity is a mechanism, not proof of universal speedup. Attribute published matrix multiplication measurements by hardware, layout, workload and library comparator. Preserve unfavorable holdouts.
6. **Reproducibility.** Exact committed tests and CI success unconfirmed; original frozen ZIP bytes not yet confirmed publicly accessible. Build an anonymous immutable supplement and clean-clone verification record.
7. **Manuscript.** The separate CC LaTeX is an early draft, not a completed 10-page paper. Bibliography, quantitative results, final figures, PDF build, anonymity and page-count audits remain open.
